# AccessTech Kenya — Official Website

AI-Powered Inclusive Employment Platform for Persons with Disabilities

🌐 **Live at:** [accesstechkenya.github.io](https://accesstechkenya.github.io)

## About

AccessTech Kenya uses AI-driven job matching, accessible e-learning, and 3D-printed adaptive devices to connect Kenya's 2.2 million persons with disabilities to remote tech careers.

**Founded by Paul Lawrence** — Computer Science graduate and person living with contractures.
